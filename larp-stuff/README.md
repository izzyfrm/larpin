# larp-stuff

Drop images and videos in this folder, commit, push. They show up under **Free larp** on the next deploy (about a minute).

- Images: `.jpg` `.png` `.webp` `.gif` `.avif`. Videos: `.mp4` `.webm` (`.mov` works in Safari only).
- The file name becomes the title: `casual-tuesday-garage.jpg` shows as "casual tuesday garage".
- Subfolders are fine. `manifest.json` is rebuilt automatically, so never edit it.
- Keep each file under 100 MB (GitHub's limit) and the whole site under 1 GB (GitHub Pages' limit).
- These files skip the automated review. Only add things you would be happy to have reviewed.
