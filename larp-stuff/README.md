# Free larp studio

Put your own authorized `.jpg`, `.jpeg`, `.png`, `.webp`, `.mp4` or `.webm` files here, including subfolders. Use descriptive filenames (e.g. `somewhere-offline.jpg`). The build generates a manifest, and the website discovers every supported file. GitHub Actions rebuilds on pushes to main. These files bypass submission moderation because they are operator-curated: review their safety, rights and metadata before committing them. Everything in this folder is public. Do not put secrets here.
